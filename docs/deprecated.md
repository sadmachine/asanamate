# Deprecated features

Deprecated features remain supported for compatibility. Use the replacement
in new commands and scripts. Removal requires a future breaking release;
no removal version is scheduled yet.

| Deprecated | Replacement | Since |
|---|---|---|
| `asanamate addons` | `asanamate extensions` | v0.3.2 |
| `keys.main.copy_link` (no default key) | `keys.main.yank`, then pick the link | v0.3.2 |
| `keys.main.copy_comment` (no default key) | `keys.main.yank` on a targeted comment, then pick the comment | v0.3.2 |
